# Serpent Peaks (Snake-City)

A 3D WebGL mountain-climbing serpent-to-human cultivation game built with TypeScript, Three.js, D3, and procedural Web Audio.

## Run Locally

**Prerequisites:** Node.js (v22+)

1. Install dependencies:
   `npm install`
2. Start the dev server:
   `npm run dev`
3. Type-check, test, and build:
   `npm run lint && npm test && npm run build`
